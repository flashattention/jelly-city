# 드림 러너 다국어(영어) 작업지시서

> "드림러너 랜딩페이지랑 웹 게임 자체도 다국어 지원돼?" → "당장 진행해. 그 사람 컴퓨터 언어 세팅에 맞게 나오게." (2026-11-22)

랜딩(5차 I-1 ~ I-4)은 이미 영어가 된다. 이번엔 **게임 안 전부**: 첫 화면 · 시작 카드 · 달리는 중 화면 · 결과 · 순위표 · 내 기록 · 꾸미기 · 같이 달리기 방 · 꿈 이름과 한 줄 설명 · 부딪힌 이유 · 서울 산책(한강) 화면까지.

## 언어 정하기 (랜딩과 같음)
- 저장한 선택 `localStorage dr-lang` → 없으면 `navigator.languages[0]` 이 `ko` 로 시작하면 한국어, 아니면 영어
- 토스 미니앱 · 젤리 서울 러너(`/seoul-walk/play/`, 한국 대회용)는 한국어 고정
- 첫 화면 · 설정에도 언어 단추(한국어 ⇄ EN), 누르면 저장하고 다시 불러옴

## 방법: 한국어 원문 → 영어 사전 (화면에서 바꿔 끼우기)
- 게임 코드 · 데이터(꿈 · 시대 · 코스 이름)는 **한국어 그대로 둔다**. 서버 기록 · 통계(자주 깬 이유 등)가 섞이지 않게
- 영어일 때만 `js/i18n/` 사전을 불러와(`await import`, 한국어 사용자는 안 받음) 화면 글씨를 바꾼다
  - 문서의 글씨 마디 · `title` · `placeholder` · `aria-label` 을 MutationObserver 로 지켜보다가 한글이 있으면 사전대로 바꿈
  - 찾는 순서: 통째로 같은 글 → 앞뒤 이모지 · 숫자 · 기호 떼고 → ' · ' 로 나눠 조각마다 → 패턴(정규식, 잡힌 조각도 다시 사전으로) 
  - 못 찾은 한글은 `window.__i18nMiss` 에 모아 두고(시험용) 사전에 더한다
- 캔버스에 그리는 글씨(꿈 이름 카드 · 3D 간판 등)는 그리는 곳에서 `tx()` 로
- 패치노트 내용은 한국어 그대로 두고 "Patch notes are in Korean" 한 줄

### 결과 (2026-11-22)
- 사전 8개 약 3,860 낱말 · 패턴 300개 (`js/i18n/`, 영어일 때만 받음 · 약 252K)
- 엔진 보강: 패턴 잡힌 조각을 못 번역해도 문장이 분명하면(정규식 밖 한글 3자 이상) 그대로 넣기(닉네임 · 가게 · 역), 숫자 + 단위, 이모지 · 숫자 앞뒤 떼기, extra 패턴이 먼저
- 사전 겹침 정리: 금 · 은 · 동 = 메달 등급, 계절 · 날씨 첫 글자 대문자
- 캔버스 글씨는 fillText · measureText 에서 바꿈. 서울 간판 낱글자 · 가게 이름은 사전에 없으면 한글 그대로(실제 서울 간판처럼)
- 영어 사용자의 기본 닉네임: Dreaming Bear 1234
- 확인 (en-US): 랜딩 팝업 · 순위표 · 꾸미기 · 다섯 세계 달리기 · 결과 · 서울 산책 시작 카드 · 설정 · 달리기 화면. 놓친 한글은 랜딩이 영어로 바뀌기 전 글과 서울 간판 글자뿐
- 성능: 달리는 10초 동안 화면 지켜보기 3.6ms (한 장면당 0.03ms)
- ko-KR 은 엔진을 받지 않고 예전 그대로
