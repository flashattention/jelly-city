# 🌙 드림 러너 랜딩 작업지시서

> 2026-11-16 사용자: "드림러너도 젤리 서울 러너처럼 고유의 아름다운 랜딩페이지. 각 월드의 컨셉과 기획의도, 지표가 잘 드러나게. 미적으로 아름답고, 기존 난이도 선택 페이지의 기능을 상단 첫 화면에서 다 할 수 있어야 하며, 내릴수록 포트폴리오적인 내용." — 메인에서 "달리러 가기"를 누르면 나오는 `/dream-runner/` 페이지를 말한다.

## 구조

- 맨 위(첫 화면) = 지금의 처음 화면 카드 그대로 (맵 · 모드 · 난이도 · 혼자 / 같이 달리기 · 코드 참가 · 꾸미기 · 순위표 · 내 기록 · 패치노트 · 명예의 전당 · 소식). 뒤에는 고른 맵의 3D 세상이 움직인다
- 카드 아래 "내려서 드림 러너 이야기 보기 ↓" → 내리면 포트폴리오가 이어진다 (같은 처음 화면 층 안에서 스크롤)
- 게임을 시작하면 처음 화면 층째 숨으니 랜딩도 같이 사라진다. 처음 화면으로 돌아오면 맨 위부터
- 토스 미니앱에서는 랜딩 부분을 보이지 않는다 (게임 첫 화면만)
