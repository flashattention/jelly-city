# 드림 러너 개선 작업지시서

서울 산책(한강맵)은 `한강맵-작업지시서.md`. 이 문서는 기본 러너(꿈나라 · 지옥 · 이공간)와 치장을 다룬다.

## 2026-11-10 제보

### 1. 웜홀 이공간: 별을 발사대 궤적에 맞추기

- [x] **무엇**: 웜홀의 초록 발사대(`vp_pads`)를 밟으면 약 15m 높이로 날아오르는데, 별은 약 3m 높이의 낮은 포물선에 놓여 있어 그냥 지나친다.
- [x] **어디에**: `public/dream-runner/js/track.js` 의 `vp_pads`.
- [x] **어떤 모습**: 발사대를 밟은 뒤 실제로 날아가는 궤적 위에 별이 줄지어 있다. 가로 위치는 출발 발판에서 도착 발판으로 이어진다. 별 개수는 지금과 같게(거리 2.5m 당 하나) 둔다.
- [x] **어떻게 확인**: 실제 `Runner` · `Track` 으로 발사대를 밟고 별 줄을 따라 움직여, 먹은 별 / 놓인 별을 고치기 전후로 잰다. 스크린샷으로 궤적 위 별을 본다.
  - 결과: 고치기 전 2~5개 → 고친 뒤 노멀 · 익스트림 · 초월 모두 놓인 별을 전부 먹음 (초월 78개 구간 79개, 앞 구간 별 1개 포함).

### 2. 발자취 띠가 간헐적으로 일자로 쭉 보임

- [ ] **무엇**: 곰 뒤의 띠(무지개 길 등 리본 발자취)가 가끔 일자로 길게 늘어나 보인다.
- [ ] **어디에**: `public/shared/js/cos-fx.js` 의 `Ribbon`.
- [ ] **어떤 모습**: 띠는 곰이 지나간 길만 따라가고, 순간 이동 · 트랙 이동 · 부활 · 공중 구간을 가로질러 이어지지 않는다.
- [x] **어떻게 확인**: 실제 게임을 여러 난이도로 달리며 프레임마다 보이는 띠 조각의 길이와 곰이 지나간 자리를 대조한다. 고치기 전에 재현하고, 고친 뒤 같은 측정이 깨끗한지 본다.
  - 결과: **재현하지 못했다.** 노멀 ~ 초월, 지옥 · 이공간 · 양자 터널, 아이템전, CPU 6배 느림(헤드리스라 프레임은 안 떨어짐)에서 그려지는 조각은 모두 6m 이하, 지나간 자리와 어긋남 없음.
  - 측정 중 찾아서 고친 것: 초고속에서 프레임이 길어지면 띠가 잘못 끊김 · 트랙 이동 뒤 옛 띠가 먼 앞에 남음 · 카운트다운 동안 제자리에 점이 쌓임.
  - [ ] **남은 일**: 일자로 보인 맵 · 난이도 · 순간(점프 뒤 · 다시 달리기 직후 등)이나 화면을 받으면 다시 본다.
