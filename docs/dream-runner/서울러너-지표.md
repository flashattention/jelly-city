# 젤리 서울 러너 이용 지표

서비스 개선과 포트폴리오에 쓰는 익명 이용 지표의 정의와 사용법.

## 무엇을 저장하나

- 기기마다 만든 무작위 아이디, 세션 아이디, 이벤트 이름과 값만 저장한다.
- 저장하지 않는 것: 구글 계정 · 이름 · 이메일 · IP · 정확한 좌표 (위치는 2km 칸과 구 단위).
- 보내지 않는 경우: Do Not Track · Global Privacy Control · 자동화 브라우저.
- 만든 사람의 플레이는 각 기기에서 주소에 `?nometrics=1` 을 한 번 붙여 뺀다 (다시 켜기 `?nometrics=0`).
- 저장 위치: 서버 `DATA_DIR/seoul-walk-metrics/날짜.jsonl` (KST 기준 하루 한 파일, 하루 200MB 상한).

## 집계 보기

```
fly ssh console -C "tar czf - -C /data seoul-walk-metrics" > sw-metrics.tgz
tar xzf sw-metrics.tgz
node tools/sw-metrics-report.mjs seoul-walk-metrics 30
```

관리자 계정으로 로그인한 세션은 `GET /api/sw/report?days=30` (Authorization 헤더) 으로도 같은 집계를 받는다. 개별 이벤트는 API 로 내보내지 않는다.

## 지표

| 묶음 | 지표 | 정의 |
|---|---|---|
| 개요 | 기기수 · 세션수 · 게임세션수 | 세션은 30분 쉬면 새로 시작. 랜딩 → 게임은 같은 세션 |
| 개요 | 총플레이시간 · 기기당 · 세션 중앙값 / p90 | 화면이 보이고 최근 60초 안에 움직인 시간만 (자리 비움 제외) |
| 일별 | DAU · 플레이 분 | KST 날짜 |
| 퍼널 | 랜딩 → 3D 표시 → 3장 이상 스크롤 → 시작 클릭 → 게임 시작 → 첫 화면 → 첫 이동 → 1분 → 5분 | 세션 단위 |
| 리텐션 | D1 · D7 · D30 · 재방문율 | 첫 방문일 기준 N일째 다시 온 기기 / 그만큼 지난 기기 |

| 행동 | 기능 사용 세션 비율 | 날기 · 가게 · 주문 · 지하철 · 열차 · 몰 · 전망대 · 설정 · 순간이동 |
| 행동 | 가게 종류별 방문수 · 방문 기기 · 머문 시간, 인기 가게 · 메뉴 · 주문 방식 | 들어갈 수 있는 가게 기준 |
| 행동 | 인기 역 · 호선 · 도착역 · 몰, 많이 본 건물(이름표), 걷기 / 날기 / 실내 시간 | |
| 행동 | 설정 변경, 시간대 · 계절 · 날씨별 플레이 시간 | |
| 랜딩 | 머문 시간, 장면 도달, 클릭 종류 · 장소, 지도 열기, 3D 성공률 | |

## 해석할 때 주의

- 인기 지역을 비교할 때는 `직접고른시작` 을 쓴다. 머문 시간은 무작위 시작의 영향을 받는다.
- 기기 = 사람이 아니다 (브라우저 저장을 지우면 새 기기, 같은 사람의 PC · 휴대폰은 두 기기).
- 수집 시작 이후의 값만 있다. 수집 주소는 공개라 조작을 완전히 막을 수 없다 (형식 검사 · 속도 제한만).
- 칸 만들기 시간에는 화면을 끊지 않으려고 쉬는 시간이 포함된다.
