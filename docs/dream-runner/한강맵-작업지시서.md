# 한강맵 작업 지시서

> 사용자가 내린 한강맵 지시를 모두 모아 둔 문서. 작업자는 이 문서를 따라가며 묻지 않고 계속 작업한다.
> 끝낸 항목은 `[x]`, 하는 중인 항목은 `[~]`, 아직 안 한 항목은 `[ ]` 로 표시해 두고 수시로 고친다.
> 마지막 정리: 2026-11-08

## 0. 큰 방향

- 한강맵은 **산책 · 힐링 게임**이다. "실제 한강 · 실제 서울을 걷고 있다"는 느낌이 가장 중요하다.
- 실제 지도 데이터를 바탕으로 만든다.
  - 구현은 코스 하나부터 해도 된다.
  - 설계는 처음부터 한강 전체 · 서울 전체를 기준으로 한다.
- **우선순위**
  1. 여의도를 고퀄리티로 전부 구현
  2. 홍대 · 남산타워 등을 실제 모습대로 아름답게 구현
  3. 그다음 다른 동네
- 모든 작업은 "최대한 섬세하게, 감성 있게".
- 새로 만든 물체 · 메시는 퀄리티와 감성을 검증하고 나서 승인한다.
  - 여러 각도 · 낮과 밤 스크린샷으로 확인한다.
  - 실제 사진과 비교한다.
- 사용자에게 계속 묻지 않는다. 이 문서를 따라 알아서 진행하고, 끝날 때마다 커밋하고 main 에 푸시한다.

## 1. 건물: 실제 생김새대로

- [ ] **모든 건물**을 실제 생김새를 찾아본 뒤 최대한 비슷하게 만든다.
  - 단순화는 해도 된다.
  - **"교회면 다 A형태, 빌딩이면 다 B형태" 같은 틀 찍어내기는 금지**
- 자료
  - **브이월드 위성영상** (키는 서버 환경변수 `VWORLD_KEY`): 지붕 모양 · 동 배치 · 옥상 구조물을 확인하는 데 쓴다. 참고용이며 게임 안에 사진을 넣지 않는다.
  - **브이월드 건물 데이터** (`LT_C_SPBD`): 공식 외곽선 · 층수 · 이름.
  - 위키미디어 등 실제 사진: 보는 용도로만 쓴다.
  - 구글 · 카카오 · 네이버 이미지를 텍스처로 쓰지 않는다.
- 이름 붙은 건물은 `LANDMARKS` 에 실제 모습을 적어 넣는다.
  - 외벽 · 색 · 지붕 색 · 왕관 · 로고 · 정면 탑 · 아치 · 천창 등.
  - 랜드마크를 감싸는 본관 조각은 같은 모습으로, 둘레 부속 건물은 따로 정한 모습으로 만든다.

## 2. 길 · 땅 · 다리

- [x] 물을 빼고 어디든 걸어갈 수 있다 (도시 골목까지). 물 바로 앞까지 갈 수 있다.
- [x] 점프로 한강 위를 건너갈 수 없다.
- [x] 다리와 경사로를 걸어 올라갈 수 있다.
  - 높은 다리는 그 밑으로 지나갈 수 있다.
  - 강 위 다리는 난간 때문에 떨어지지 않는다.
- [x] 하늘에 떠 있는 다리는 없게 한다: 끝이 땅까지 내려오고, 교각이 있다.
- [x] 나무가 다리를 가로막지 않는다.
- [ ] 도시 바닥 다듬기: 인도 · 횡단보도 · 차선 · 연석 · 신호등 · 표지판 · 가게 앞.
- [ ] 강변 계단 · 물거품 · 가로등 머리와 불빛 다듬기 (가로등은 기둥만 있으면 안 되고 불빛이 있어야 한다).

## 3. 부딪힘 · 움직임

- [x] 건물 · 나무 · 사람 · 차 등 모든 것은 부딪히면 뚫고 지나가지 못한다.
- [x] 모든 건물 벽을 타고 올라갈 수 있다 (젤리시티처럼). 옥상에 설 수 있다.
- [x] 3단 점프 (2단 · 3단은 공중제비). 숙이기.
- [x] 키를 누르고 있을 때만 움직인다. 방향은 마우스로 돌린다 (오픈월드처럼).
- [x] Shift 가속. 한번 가속하면 멈출 때까지 그 속도를 유지한다.
- [x] 기본 속도를 높게 둔다 (전에 2배로 올림).
- [x] 카메라
  - 땅속으로 들어가지 않는다.
  - 다리 위에서 다리 밑으로 들어가지 않는다.
  - 높은 벽을 탈 때 끝까지 따라간다.
- [x] 캐릭터와 모든 곰을 작게 한다.
- 드림러너 PC 규칙(숙이기 0.75초 등)은 바꾸지 않는다.

## 4. 사람 (NPC)

- [x] 털 색 · 복장 · 관계를 다양하게 한다: 가족 · 연인 · 친구 · 피크닉 · 캠핑. 공원 안쪽에도 둔다.
- [x] 달리는 곰은 러닝복과 사회복을 섞고, 안 달리는 곰은 상황에 맞는 옷을 입는다.
- [x] 계절 · 날씨 · 시간대와 실시간 혼잡도에 따라 사람 수를 바꾼다. 벚꽃 피는 날엔 연인이 매우 많다.
- [~] 지역마다 다른 사람들
  - 직장 건물 근처엔 양복 · 와이셔츠 입은 직장인이 많다.
  - 홍대엔 코스프레 · 스트리트 패션이 많다.
- [ ] 많은 도시 NPC: 인도를 걷고, 가게를 드나든다.

- 구조: 서버가 서울시 API 를 실시간으로 불러 서버에 기억하고, 모든 클라이언트는 서버에서 읽는다.
  - 키는 서버 환경변수에만 둔다. 저장소에 올리지 않는다.
- [x] 버스: 여의도를 지나는 실제 노선 15개를 실제 GPS 위치대로 보여 준다. 간선은 파랑, 지선은 초록, 노선 번호판을 단다.
- [x] 도로 · 자동차 수: 실제 도시데이터의 도로 소통 · 속도를 따른다.
- [x] 날씨(자동): 실제 서울 날씨를 따른다.
- [x] 지하철 출입구 위치 + 실시간 도착 안내. 한강철교 1호선 열차.
- [~] **지하철역** (여의도역 · 여의나루역 · 국회의사당역 · 샛강역 등)
  - [x] 출구: 실제 위치 · 번호대로, 화강석 벽 · 유리벽 · 둥근 유리 지붕 · 노란 번호 · 안내 기둥 · 밤 조명
  - [x] 내부: 출구 계단으로 내려가면 대합실(개찰구 · 발매기 · 번호별 출구 계단 · 도착 안내판) → 호선별 승강장(스크린도어 · 점자블록 · 역 이름판 이전/다음 역 · 벤치 · 광고 · 열차가 들어와 서고 문을 연다) → 번호 출구로 나가면 실제 그 출구로
  - [x] 열차 타기: 열린 문으로 타면 호선별 열차 안(긴 의자 · 노약자석 · 임산부석 · 손잡이 · 노선도 · 안내 화면 · 터널 불빛) → 다음 역 승강장에 내린다
  - **외관과 n번 출구**: 실제 위치 · 번호 · 모양대로.
    - 출구 지붕 모양 · 번호판 · 호선 색 · 역 이름판.
  - 내부: 실제와 똑같이 할 필요는 없다. 작업자가 알아서 감성 있게 만든다.
    - 대합실 · 개찰구 · 승강장 · 스크린도어 · 안내판.
- [ ] 지하철 열차: 실제 노선도와 시간표, 실시간 위치대로 다닌다.
  - 호선마다 실제 열차처럼 생긴다 (외관 색 띠 · 모양).
  - 내부도 호선마다 실제 열차 내부처럼 만든다.
  - 탈 수 있게 한다.

## 작업 규칙 (작업자용)

- 운영 서버에는 시험 기록을 만들지 않는다. 로컬에서 임시 데이터 폴더로 시험한다.
- 시험 페이지 `public/dream-runner/_hg.html` 은 커밋하지 않는다.
- 커밋 메시지는 한국어로 쓴다. 끝날 때마다 바로 main 에 푸시한다.
- API 키는 Fly secrets 에만 둔다.
  - `SEOUL_SUBWAY_KEY`
  - `SEOUL_CITY_KEY`
  - `SEOUL_BUS_KEY`
  - `VWORLD_KEY`
