# 한강맵 작업 지시서

> 사용자가 내린 한강맵 지시를 모두 모아 둔 문서. 작업자는 이 문서를 따라가며 묻지 않고 계속 작업한다.
> 끝낸 항목은 `[x]`, 하는 중인 항목은 `[~]`, 아직 안 한 항목은 `[ ]` 로 표시해 두고 수시로 고친다.
> 마지막 정리: 2026-11-08

## 0. 큰 방향

- 한강맵은 **산책 · 힐링 게임**이다. "실제 한강 · 실제 서울을 걷고 있다"는 느낌이 가장 중요하다.
- 실제 지도 데이터를 바탕으로 만든다.
  - 구현은 코스 하나부터 해도 된다.
  - 설계는 처음부터 한강 전체 · 서울 전체를 기준으로 한다.
- **우선순위**
  1. 여의도를 고퀄리티로 전부 구현
  2. 홍대 · 남산타워 등을 실제 모습대로 아름답게 구현
  3. 그다음 다른 동네
- 모든 작업은 "최대한 섬세하게, 감성 있게".
- 새로 만든 물체 · 메시는 퀄리티와 감성을 검증하고 나서 승인한다.
  - 여러 각도 · 낮과 밤 스크린샷으로 확인한다.
  - 실제 사진과 비교한다.
- 사용자에게 계속 묻지 않는다. 이 문서를 따라 알아서 진행하고, 끝날 때마다 커밋하고 main 에 푸시한다.
