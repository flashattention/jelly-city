# 젤리 아케이드 작업지시서

2026-11-13 건의: "새 게임으로 젤리 아케이드(크레이지아케이드 3D 버전)도 만들어 줘."

- **원칙:** 크레이지아케이드는 남의 게임이다. 그래서 '격자 미로에 폭탄을 놓아 십자로 터뜨리는 대전' 장르만 빌린다.
  - 이름 · 캐릭터 · 아이템 모양 · 맵 · 음악 · 화면 배치는 젤리 게임즈 것으로 새로 만든다.
  - 물풍선 · 바늘 · 그 게임 캐릭터 이름처럼 그 게임을 떠올리게 하는 것은 쓰지 않는다.
- **위치:**
  - 화면: `public/jelly-arcade/`
  - 방 · 판정 서버: `server/jelly-arcade/`
  - 메인 화면 카드: `public/index.html`
- **보는 방식:** three.js 3D. 비스듬히 위에서 내려다보는 카메라로, 격자가 한눈에 보이게 한다.

## 1. 기본 판 (혼자 · 봇)
- [ ] 1-1 격자 맵 13×11
  - 부서지지 않는 블록 · 부서지는 젤리 상자 · 빈칸을 둔다.
  - 시작 구석 네 곳은 늘 비워 둔다.
- [ ] 1-2 젤리 곰 이동
  - PC는 방향키 · WASD, 휴대폰은 조이스틱으로 움직인다.
  - 격자 칸 가운데로 부드럽게 붙어 모서리에 걸리지 않게 한다.
- [ ] 1-3 젤리 폭탄
  - Space(휴대폰은 버튼)로 발밑에 놓는다. 2.5초 뒤 십자로 젤리 물결이 퍼진다.
  - 물결은 블록에서 멈춘다. 상자는 부수고 멈춘다.
  - 다른 폭탄에 닿으면 연쇄로 터진다.
- [ ] 1-4 갇힘 · 구조
  - 물결에 맞은 곰은 젤리 덩어리에 갇혀 5초 동안 천천히 흔들린다.
  - 같은 편이 닿으면 풀려나고, 상대가 닿거나 시간이 다 되면 탈락한다.
- [ ] 1-5 아이템
  - 상자를 부수면 일정 확률로 나온다. 모두 젤리 게임즈식 이름 · 모양으로 만든다.
    - 별사탕: 폭탄 수 +1
    - 시럽병: 물결 길이 +1
    - 운동화: 속도 +
    - 탈출 젤리: 갇혔을 때 한 번 스스로 풀려남
- [ ] 1-6 봇 3마리
  - 위험한 칸을 피하고, 상자를 부수고, 아이템을 줍고, 상대를 노린다.
  - 쉬움 · 보통 두 단계를 둔다.
- [ ] 1-7 판 흐름
  - 3분이 지나면 바깥부터 블록이 내려와 판이 좁아진다.
  - 마지막에 남은 편이 이긴다.
  - 결과 화면에서 다시 하기 · 처음으로를 고른다.
- 확인: PC · 휴대폰 크기에서 낮 조명 사진을 찍는다. 봇과 한 판을 끝까지 돌리고 60프레임이 나오는지 본다.

## 2. 감성 · 맵
- [ ] 2-1 맵 3개, 모두 새로 그린다.
  - 사탕 마을
  - 젤리 공장(컨베이어가 곰을 민다)
  - 얼음 과자 섬(미끄러짐)
- [ ] 2-2 꾸밈
  - 젤리처럼 말랑한 재질(반투명 · 하이라이트), 터질 때 출렁임, 그림자를 넣는다.
  - 상자가 깨지면 조각이 튄다.
  - 소리를 넣는다. 다른 게임에 있는 것처럼 Web Audio로 직접 만든다.
- [ ] 2-3 치장
  - 젤리 게임즈 공통 치장(`server/cosmetics.js`)을 곰에 입힌다.
- 확인: 맵마다 사진을 찍어 기본 도형 느낌이 없는지 본다.
