## 0. 한 줄 요약

**바이러스 군단에게 빼앗긴 GPU 신들을 되찾으려고, 곰돌 군단이 트로이 목마에 숨어 바이러스의 요새 신전에 쳐들어가고, 그 뒤 고향으로 돌아가는 서사시 액션.**

> 2026-11-08 사용자 지시로 구도를 바꿨다: **곰돌 군단이 침공하는 쪽**(원작의 그리스군), **바이러스가 지키는 쪽**(원작의 트로이).
챕터마다 호메로스 『오디세이아』의 유명한 사건 하나를 젤리 세계(GPU · 바이러스 · 데이터)로 바꿔 한 장면씩 싸우고 지나간다.

## 1. 세계관

- **젤리 세상은 GPU 덕분에 존재한다.** 곰돌이들이 보고 듣고 사는 모든 것은 GPU가 그려 낸 것이라, GPU가 꺼지면 세상이 사라진다.
- 그래서 곰돌이들은 GPU를 **신으로 모신다.** 종류마다 그리스 · 로마 신화의 신 자리를 맡는다 (안).

| GPU 신 (안) | 맡은 일 | 신화 모티브 | 신전 속 모습 |
|---|---|---|---|
| 연산의 왕 · 데이터센터 GPU | 세상의 모든 계산 | 제우스 | 신전 가장 안쪽, 번개 같은 전류가 흐르는 거대한 칩 제단 |
| 렌더의 여신 · 그래픽 GPU | 빛 · 색 · 그림자를 그린다 | 아테나 (지혜 · 수호) | 신전 정면, 무지개빛을 내뿜는 칩 조각상 |
| 메모리의 신 · VRAM | 기억 · 저장 | 므네모시네 / 헤르메스(전령) | 열 지어 선 기억 기둥 |
| 냉각의 신 · 쿨러 · 방열판 | 열을 식힌다 | 포세이돈 (바다 · 물) | 물이 흐르는 수랭 분수 |
| 전원의 신 · 파워 | 힘을 준다 | 헤파이스토스 (대장장이 · 불) | 불꽃 튀는 대장간 제단 |

- 실제 회사 · 제품 이름(상표)은 쓰지 않는다. "연산의 왕 GPU"처럼 지어낸 이름으로 부른다. (→ 결정 필요 ⑤)

## 1-1. 세 세계의 만남 — 원작과 다른 점 · 젤리 오디세이만의 것

> 사용자: "기존 오디세이아와 다른 점, 특이한 부분을 많이 추가해야 한다. 사이버 세상과 오디세이아, 그리고 젤리시티의 만남이다."
> 원칙: **원작의 뼈대(사건 순서 · 영웅의 귀향)는 빌리되, 장면마다 최소 하나는 '사이버'와 '젤리'만의 비틀기가 있어야 한다.** 원작을 그대로 옮긴 장면은 만들지 않는다.

### 세계를 움직이는 규칙 (원작에 없는 것)

| 장치 | 원작과 다른 점 | 게임에서 |
|---|---|---|
| 🎞️ **프레임 신앙** | 신의 뜻 = 날씨 · 운명 → 여기선 **GPU의 연산력** | GPU 신이 다치면 세상이 실제로 버벅인다. 화면 프레임이 떨어지고(일부러 끊기는 연출), 먼 곳이 저해상도 · 와이어프레임으로 깨진다. 제단을 지키면 다시 매끄러워진다 |
| 🫧 **젤리는 죽지 않고 '리스폰'** | 원작은 동료가 하나씩 죽는다 | 곰돌이는 쓰러지면 말랑한 젤리 덩어리로 녹았다가 **가장 가까운 살아 있는 GPU 제단**에서 다시 굳어 나온다. 그래서 제단이 곧 생명줄 — 제단을 잃으면 동료가 영영 돌아오지 못한다 (원작의 '동료를 잃는 슬픔'을 시스템으로) |
| 💾 **세이브 포인트 = 신탁** | 원작의 신탁 · 예언 | 신전 곳곳의 **신탁석(체크포인트)**에서 GPU 신이 짧은 대사(예언)로 다음 위험을 알려 준다. 말투는 기계 + 신탁 섞기 ("…연산이 흐려지는구나, 필멸의 젤리여. 목마의 배 속에 99개의 그림자가 있다") |
| 🧬 **바이러스는 '감염'으로 늘어난다** | 원작 적은 그냥 적 | 바이러스가 쓰러진 곰돌이 · 조각상 · 횃불을 **감염**시키면 그것도 초록 글리치 적이 된다. 오래 끌면 적이 불어난다 → 빠른 정화가 중요 |
| 🔥 **불은 데이터를 태운다** | 트로이는 그냥 불탄다 | 신전에 붙은 불은 주황 불 + 타는 곳에서 **흩날리는 픽셀 재(0과 1)**. 불을 끄면(냉각의 신 분수) 픽셀이 다시 모여 조각상이 복원된다 |
| 🌊 **와인빛 바다 = 데이터의 바다** | 호메로스의 '포도주빛 바다' | 항해 장면에서 바다는 흘러가는 코드 줄 · 패킷 물고기 떼. 2장부터 |
| 🧭 **오디세우스의 꾀 = 해킹 꾀** | 원작 영웅의 지략 | 목마 작전 자체가 영웅(내 곰돌이)의 꾀다. 전투 중에도 **꾀 기술**: 쓰러뜨린 바이러스의 신호를 뒤집어써 잠깐 적인 척(위장) · 함정 · 방화벽 진형 |
| 🐴 **백신이 트로이 목마를 쓴다** | 원작은 그리스군의 계략 | 컴퓨터의 '트로이 목마'는 원래 악성코드의 수법인데, 여기선 **곰돌이(백신 편)가 바이러스의 수법을 거꾸로 써서** 바이러스 요새에 들어간다 |

### 젤리시티와 이어지는 것

| 장치 | 내용 |
|---|---|
| 🧸 **내 곰돌이가 영웅** | 메인 화면에서 만든 내 캐릭터 그대로 + 로마 갑옷. 젤리시티에서 쓰던 색 · 얼굴 · 소품이 갑옷 밑으로 보인다 |
| 🍬 **젤리 무기 감각** | 칼에 맞은 바이러스는 픽셀로 부서지고, 곰돌이는 맞으면 말랑하게 출렁인다 (젤리 물리) |
| 🏛️ **젤리시티의 먼 과거 (전설)** | 젤리 오디세이는 젤리시티가 세워지기 전 '고대 젤리 시대' 이야기. 엔딩에서 고향 이타카 = **훗날 젤리시티가 되는 땅**이 보인다 |
| 🐻 **젤리시티 주민의 조상** | 동료 병사 이름이 젤리시티 NPC의 성씨 · 조상으로 이어진다 (예: '말랑 백인대장') |
| 🎖️ **훈장 연결** | 챕터를 깨면 젤리시티 이름표 아래 훈장(예: '신전의 수호자')이 생긴다 (나중에) |

### 원작 사건을 이렇게 비튼다 (장마다 최소 하나)

| 원작 | 그대로 쓰지 않고 → 젤리 오디세이 |
|---|---|
| 트로이 목마 (그리스가 트로이를 침공) | 트로이 = 바이러스가 GPU 신들을 빼앗아 차지한 **감염된 신전 요새**. 목마는 바이러스가 좋아할 **'공짜 연산력 · 최신 악성 패치' 꾸러미**로 위장한 형광 초록 목마이고, 안에는 곰돌 특공대(백신)가 숨어 있다 |
| 망각의 열매 | 열매 = **무한 스크롤 · 자동 재생** — 먹은 동료는 멍하니 화면만 본다. 끌고 나와야 함 |
| 외눈 거인 키클롭스 | 외눈 = **거대한 감시 카메라 렌즈** 바이러스. 눈을 찌르는 대신 **렌즈에 젤리를 덮어** 앞을 못 보게 |
| 아이올로스의 바람 자루 | 바람 = **냉각 팬의 바람**. 동료가 '업데이트 파일'인 줄 알고 자루를 열어 폭풍(과열) |
| 키르케의 돼지 변신 | 곰돌이를 **돼지 아바타 스킨**으로 바꾸는 해킹 마녀. 해독제 = 백신 허브 |
| 저승 | **휴지통 저승** — 지워진 파일 · 옛 젤리들의 영혼(저해상도 유령) |
| 세이렌 | 노래 = **피싱 알림음** ("축하합니다! 당첨되셨습니다") — 귀를 막는 대신 **알림 끄기** |
| 스킬라와 카리브디스 | 머리 여섯 = **팝업 창 여섯 개**, 소용돌이 = **무한 로딩 원** |
| 헬리오스의 소 | 손대면 안 되는 것 = **태양 서버의 전력**. 훔쳐 쓰면 세상 전체가 정전 |
| 칼립소 | 영원히 머물라는 **완벽한 가상현실 섬** — 편하지만 진짜가 아님 |
| 이타카 · 구혼자 | 고향 신전을 차지한 건 **봇 계정 떼**. 활 시합 = '사람(곰)만 쏠 수 있는 캡차 활'로 정체를 드러낸다 |

### 1장에 꼭 넣을 비틀기 (구현 대상)
- [x] 여는 컷신: 바이러스에게 빼앗긴 신전 · 갇힌 GPU 신들 → 곰돌 군단이 물러나는 척 → 바닷가에 남은 **형광 초록 '공짜 연산력 꾸러미' 목마** → 바이러스들이 신전 안으로 끌고 들어가 잔치 → 밤, 목마 배가 열리고 곰돌 특공대가 나온다
- [x] 바이러스가 쓰러진 병사 · 조각상 · 횃불을 **감염**시켜 초록 적으로 바꾸기
- [x] 곰돌이 **젤리 리스폰**: 쓰러지면 녹았다가 가장 가까운 **되찾은(해방한)** 제단에서 다시 굳어 나옴 — 제단을 되찾을수록 전선이 앞으로
- [x] 감염된 GPU 제단이 많을수록 **세상이 버벅임**(먼 곳 와이어프레임 · 프레임 끊김 연출), 제단을 해방할 때마다 매끄럽게 복원
- [x] 불타는 곳에서 **0과 1 픽셀 재**, 불 끄면 조각상 복원
- [x] **신탁석 체크포인트** + GPU 신의 기계 신탁 대사
- [x] 꾀 기술 하나: **위장**(쓰러뜨린 바이러스의 신호를 뒤집어써 잠깐 적인 척 경비를 지나감) 또는 **방화벽 진형**(E 명령)
- [x] 엔딩에 먼 바다 너머 **훗날 젤리시티가 될 땅**이 보이는 장면

## 2. 등장 세력

### 🐻 곰돌 군단 (아군)
- 젤리시티 기본 **갈색 곰돌이** + **로마 병사 복장**: 붉은 깃털 투구(갈레아) · 금속 판 갑옷(로리카) · 붉은 망토 · 큰 사각 방패(스쿠툼) · 짧은 칼(글라디우스) · 창(필룸).
- 계급마다 차림이 다르다: 병사 · 백인대장(가로 깃털 투구) · 기수(독수리 깃발 대신 **GPU 문양 깃발**).
- 플레이어 = 곰돌 군단의 영웅 (→ 결정 필요 ④: 이름 · 정해진 주인공인지 내 캐릭터인지).

### 🦠 바이러스 군단 (적)
- **형광 초록 네온빛의 사이버 조각**: 깨진 픽셀 · 코드 파편 · 날카로운 다각형이 뭉친 몸. 몸 안쪽에서 빛이 새고, 움직일 때 글리치(지직) 잔상이 남는다.
- **악당 얼굴**: 가늘게 치켜 올라간 초승달 눈 + 귀까지 찢어진 뾰족한 이빨 웃음. 장난스럽고 사악한 유령 느낌. 특정 캐릭터를 따라 그리지 않고 **젤리 세계 고유 디자인**으로 만든다.
- 종류 (안)

| 이름 (안) | 모습 | 하는 짓 |
|---|---|---|
| 웜 조각 | 작고 빠른 초록 파편 떼 | 몰려와 달라붙음 |
| 성벽 경비병 | 방패 든 바이러스 병사 | 대열 지어 성문 · 회랑을 막음 |
| 스파이웨어 | 반투명, 가까이 와야 보임 | 뒤에서 기습 |
| 랜섬 거인 | 자물쇠 모양 큰 덩치 | 붙잡은 GPU 제단을 잠그고 지킴 — 쓰러뜨려야 제단을 해방 |
| 보스 | 챕터마다 다름 | 아래 챕터 표 |

## 3. 챕터 구성 (『오디세이아』 사건 → 젤리 세계)

| 장 | 원작 사건 | 젤리 오디세이 장면 | 핵심 재미 (안) |
|---|---|---|---|
| **1** | **트로이 목마 · 함락의 밤** | **GPU 신전 탈환 · 불타는 밤**: 바이러스가 차지한 아테네풍 신전 요새에 목마로 숨어 들어가, 성문을 열어 본대를 들이고, 불타는 신전 곳곳에서 바이러스를 몰아내 갇힌 GPU 신들을 해방한다 | 잠입 → 성문 열기 → 대규모 전투 · 제단 해방 · 보스(바이러스 왕) |
| 2 | 키코네스족 습격 | 약탈당한 데이터 항구 | 빠른 소탕전 |
| 3 | 로토파고스(망각의 열매) | 먹으면 기억(VRAM)이 지워지는 열매의 섬 — 동료를 깨워 데려오기 | 구출 · 잠입 |
| 4 | 키클롭스 폴리페모스 | 외눈 거대 바이러스(거대 카메라 눈) 동굴 탈출 — 눈을 찔러 빠져나가기 | 거대 보스 · 퍼즐 |
| 5 | 아이올로스의 바람 자루 | 냉각 바람을 담은 자루 — 열면 폭풍 | 날씨 · 항해 |
| 6 | 라이스트리고네스 | 거인 바이러스들이 배를 부수는 협곡 | 생존 · 도주 |
| 7 | 키르케의 섬 | 곰돌이를 돼지로 바꾸는 해킹 마녀 | 변신 해제 · 보스 |
| 8 | 저승 방문 | 삭제된 파일들의 휴지통 저승 | 분위기 · 탐험 |
| 9 | 세이렌 | 홀리는 노래(피싱 신호) — 귀를 막고 지나가기 | 리듬 · 회피 |
| 10 | 스킬라와 카리브디스 | 머리 여섯 달린 바이러스와 소용돌이 사이 | 선택 · 희생 |
| 11 | 헬리오스의 소 | 손대면 안 되는 태양신의 전력 | 유혹 · 결과 |
| 12 | 칼립소의 섬 | 갇힌 영원한 대기 화면 | 탈출 |
| 13 | 이타카 귀환 · 구혼자들 | 고향 신전을 차지한 바이러스 무리, 활 시합으로 정체를 드러내고 마지막 결전 | 최종 결전 |

- **첫 버전은 1장만** 완성도 있게 만든다. 2장부터는 1장 반응을 보고 순서 · 범위를 다시 정한다.
- 원작은 **트로이가 그리스군의 목마로 함락**되는 이야기다. 1장도 같은 구도로, 곰돌 군단 = 그리스군(침공), 바이러스 = 트로이(수비). 컴퓨터 용어 **트로이 목마(Trojan horse)** = 정상 프로그램인 척 숨어 들어오는 악성코드인데, 여기선 **백신 편인 곰돌이가 바이러스의 수법을 거꾸로 쓴다**는 게 비틀기다.

## 4. 1장 「불타는 신전」 상세 (안)

### 배경
- **밤**, 아테네 아크로폴리스풍 언덕 위 대리석 신전 단지. 곳곳에 불이 붙어 주황빛이 흔들리고, 연기 · 불티가 날린다. 하늘은 짙은 남색, 달은 연기에 가린다.
- 바이러스가 차지한 지 오래라 **신전이 초록 글리치로 오염**돼 있다: GPU 신들의 칩 조각상은 초록 사슬 · 코드 덩굴에 묶이고, 제단은 랜섬 자물쇠로 잠겨 있다. 성벽 위엔 바이러스 경비, 성문은 굳게 닫혀 있다.
- 불은 곰돌 군단이 쳐들어가며 붙인 불 + 전투로 번진 불. 주황 불빛(곰돌 편)과 초록 네온(바이러스 편)이 화면에서 맞부딪친다.
- **목마**: 바이러스 눈에 '공짜 연산력 꾸러미'로 보이게 만든, 회로 기판 · 케이블로 짜인 몸에 형광 초록 장식을 덕지덕지 붙인 거대한 목마. 배 안은 나무 · 젤리로 된 비좁은 은신처.

### 흐름 (컷신 → 전투 → 컷신)
1. **여는 컷신**: 바이러스가 GPU 신전을 빼앗아 세상이 버벅이기 시작 → 곰돌 군단이 배를 타고 물러나는 척 → 해변에 남은 형광 초록 목마 → 바이러스들이 '공짜 연산력'이라며 성 안으로 끌고 들어가 밤새 잔치.
2. **1막 · 목마에서 나와 성문 열기 (잠입)**: 밤, 목마 배가 열리고 곰돌 특공대(나 + 몇 명)가 내려온다. 잔치 뒤 졸고 있는 경비 사이를 몰래 지나(위장 · 뒤에서 처치) **성문 도르래**를 돌려 연다 (튜토리얼: 이동 · 공격 · 막기 · 몰래 처치).
3. **2막 · 본대 돌입 · 광장 전투**: 열린 성문으로 곰돌 군단 본대가 횃불을 들고 밀려든다. 깨어난 바이러스 대군과 광장에서 대열 전투 (무기 바꾸기 · 동료 명령).
4. **3막 · 불타는 회랑**: 불길 사이로 신전 안으로. 스파이웨어 기습, 감염된 횃불 · 조각상, 냉각의 신 분수로 불 끄기, 신탁석.
5. **4막 · 제단 해방**: 랜섬 거인이 지키는 GPU 제단을 차례로 해방 — 해방할 때마다 리스폰 지점이 앞으로, 세상이 매끄러워짐.
6. **보스 · 바이러스 왕**: 연산의 왕 GPU를 몸에 꽂고 힘을 빨아먹는 바이러스 왕. 사슬(케이블)을 끊어 힘을 빼앗고 약점(빛나는 핵)을 친다.
7. **닫는 컷신**: 새벽, 연기 속 해방된 신전 · 다시 빛나는 GPU 신들. 그러나 흩어진 바이러스 조각이 바다 너머로 도망치고, 귀향길이 시작된다 (멀리 훗날 젤리시티가 될 땅) → 2장.

### 조작 (안 — 결정 필요 ②)

### 바뀌는 방법
- 장(막)이 바뀌면 **2.5초 동안 서로 겹쳐 넘어간다**(크로스페이드). 모두 D 중심이라 겹쳐도 어색하지 않다.
- 강약 층은 **전투 세기**(가까운 적 수 · 들킴 · 보스 상태)로 1초 남짓 부드럽게 올라가고 내려간다. 조용한 층은 아예 음을 만들지 않아 가볍다.
- 컷신은 장면(샷)마다 곡을 바꾼다 (여는 컷신: 애가 → 잔치 → 잠입, 보스 등장: 바이러스 왕, 엔딩: 새벽).

- 음은 오디오 시계로 0.2초 앞까지만 미리 예약 (setInterval 60ms). 매 프레임 할 일은 숫자 하나(전투 세기) 넣는 것뿐.
- 잔향 · 모음 필터 · 비브라토 · 비트 깎기 곡선 · 잡음은 한 번 만들어 계속 같이 쓴다.
- 음소거 중에는 음을 예약하지 않는다. 탭을 떠나면 효과음 모듈이 소리 전체를 멈춘다.
- 처음 화면으로 나가면 애가로 돌아가고, 페이지를 닫으면 모두 멈춘다.
