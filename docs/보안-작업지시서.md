## 2. HTTP 공통
- [x] 2-1 보안 헤더를 모든 응답에 붙인다.
  - `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Strict-Transport-Security`.
  - `Content-Security-Policy`: 쓰는 출처(자기 도메인 · cdn · 구글 로그인 · 토스)만 허용. 처음엔 Report-Only 로 깨지는 곳을 찾고, 그다음 켠다.
  - `frame-ancestors`: 토스 미니앱 등 허용한 곳만.
  - 결과: `server/index.js` secHeaders. nosniff · Referrer-Policy · HSTS(180일) · Permissions-Policy(카메라 · 마이크 끔) · CSP.
    - CSP 출처: 자기 주소(+ 같은 호스트 ws/wss) · cdn.jsdelivr.net(three) · accounts.google.com · apis.google.com(구글 로그인) · www.youtube.com · s.ytimg.com(젤리시티 TV) · fonts.googleapis/gstatic. 인라인 스크립트(import map · 설정 한 줄)가 23개 페이지에 있어 `script-src` 에 'unsafe-inline' 은 남겼다(바깥 출처 스크립트는 막힘). `object-src 'none'` · `base-uri 'self'` · `form-action 'self'`.
    - frame-ancestors: 'self' + `*.toss.im` · `*.tossmini.com` (토스 미니앱 번들은 따로 실려 웹 CSP 와 상관없지만 혹시 감싸 띄울 때를 위해).
    - Report-Only 로 먼저 띄워 헤드리스 크롬으로 허브 · 드림 러너 · 서울 산책(랜딩 · 게임) · 젤리시티 · 2D 게임 10개 · 개인정보 · 관리자 페이지를 열어 위반 0건 확인 → `enforce` 로 켰다. 위반은 `/api/csp-report` 로 모여 보안 사건(csp)에 쌓인다. 문제가 생기면 Fly 에 `CSP_MODE=report` 를 넣으면 바로 보고만 하는 모드로 돌아간다.

- [x] 2-2 정적 파일 경로 넘어가기를 막는다.

## 10. 서버가 바깥을 부르는 곳 (`server/seoul.js` 등)
- [x] 10-1 SSRF 막기: 사용자가 준 값이 바깥 요청 주소 · 매개변수에 그대로 들어가지 않게 한다. 지역 · 노선 · 역 이름은 허용 목록으로만 받는다.
  - 점검: 서버가 바깥을 부르는 곳 = 서울 지하철 · 버스 · 도시 데이터(`seoul.js`), 구글 tokeninfo(`auth.js`), 토스 파트너 API(`toss.js`), OpenAI(`llm.js`). 모두 **주소(호스트 · 경로 앞부분)는 코드에 고정**이고 사용자 값은 encodeURIComponent 된 맨 끝 조각 · 숫자 · JSON 본문으로만 들어간다 → 다른 호스트 · 내부 주소(169.254 …)로 보내는 SSRF 는 없었다.
  - 결과(예산을 태우는 길 막기 · 허용 목록):

## 사용자 할 일 (작업자가 할 수 없는 것)

1. **서울 열린데이터 · 버스 API 키 보호 (10-2)** — 이 API 들은 http 로만 열려 있어 키가 암호화 없이 오간다.
   - 공공데이터포털 · 서울 열린데이터광장 콘솔에서 키 사용량을 가끔 확인하고, 이상하게 많으면 키를 다시 받는다(재발급 후 `fly secrets set -a jelly-city SEOUL_SUBWAY_KEY=새키 SEOUL_BUS_KEY=새키 SEOUL_CITY_KEY=새키`).
   - 콘솔에 "호출 IP 제한" 이 있으면 Fly 서버의 나가는 IP 만 허용한다(`fly ips list -a jelly-city`, 나가는 IP 는 `fly ssh console -a jelly-city -C "wget -qO- ifconfig.me"`).
2. **배포 도구 버전 고정 (11-1, 권장)** — `.github/workflows/deploy.yml` 의 `flyio/flyctl:latest` 를 지금 쓰는 버전 태그(예: `flyio/flyctl:v0.3.x`)로 바꾸기. 워크플로 파일이라 작업자가 함부로 바꾸지 않았다.
3. **CSP 가 무언가를 막는다는 제보가 오면** — `fly secrets set -a jelly-city CSP_MODE=report` 로 바로 "보고만" 으로 돌릴 수 있다. 위반 내용은 관리자 보안 요약(csp)에 쌓인다.
4. **새 도메인을 붙이면** — 웹소켓 Origin 허용에 `fly secrets set -a jelly-city WS_ORIGINS=https://새도메인` (같은 호스트로 들어오는 접속은 원래 허용).
