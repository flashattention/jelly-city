## 1. 2026-11-14 피드백

1. [x] **게이지를 화면 가운데에** — "부글 · 탱글 등 게이지를 가진 영웅의 게이지가 화면 중앙에 표시되면 좋을 듯(지금 오른쪽 아래라 보기 불편)"
   - 부글 생체 자원 · 탱글 에너지를 조준점 아래 가운데 막대(`#extra`, 파라 연료 · 쌩쌩 점멸과 같은 자리)로도 보여 준다. 오른쪽 아래 숫자는 그대로
2. [x] **토닥 E(부활) 쿨타임이 안 걸림**
   - 원인: 서버가 쿨타임을 확인하기 전에 부활부터 하고, 성공해도 화면에 30초 쿨타임을 알려 주지 않는다(화면은 1초만 건다)
   - 고침: 서버에서 쿨타임이 남았으면 거절하고 남은 시간을 알려 주기, 성공하면 30초를 화면에 알려 주기
3. [x] **토닥: Shift 로 날아가는 동안 빨대(치유 · 강화 줄기)가 끊기고, 빨대를 쓰는 중엔 Shift 가 안 됨**
   - 원인 ① 날아가는 동안을 '바쁨'으로 쳐서 줄기가 막힌다 ② 줄기는 한 번 잡으면 시선을 돌려도 붙어 있는데 수호천사는 정면 25° 안을 다시 찾아서 "조준해요"로 실패한다
   - 고침: 날아가는 동안에도 줄기 유지, 수호천사는 지금 줄기로 잇고 있는 아군을 먼저 대상으로
4. [x] **칼바람 봇이 용검(궁극기) 뒤 멍청해짐**
   - 원인: 용검 중엔 6.5m 안에서만 베는데, 움직임은 표창 거리(약 18m)를 지키도록 그대로였다
   - 고침: 용검 · 원시의 분노 중엔 근접 전용 움직임(곧장 붙고 앞에서 옆걸음), 멀면 질풍참으로 파고들기
