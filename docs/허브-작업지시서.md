### 1. 게임 카드의 누적 플레이 배지는 숫자가 넉넉한 게임만

- [x] **무엇**: 게임 카드 오른쪽 위 `⏱️ 누적 n분 · n판` 배지를 모든 게임에 붙이지 않는다. 숫자가 작으면 오히려 인기 없어 보인다.
- [x] **어디에**: `public/hub/hub.js` 의 `/api/playtime/all` 처리.
- [x] **어떤 모습**: 누적 60분 이상이고 50판 이상인 게임만 배지를 보인다. 나머지 카드는 배지 없음 (`플레이 집계 중` · `순위표 n명` 도 안 보임). 카드 순서(많이 한 게임부터)는 그대로.
- [x] **어떻게 확인**: 로컬에서 숫자를 넣은 응답으로 메인 화면을 열어, 기준 넘는 카드만 배지가 있는지 본다. 운영 서버 숫자(2026-11-11: 드림 러너 1,280분 · 2,653판, 나머지 13분 · 5판 이하)로는 드림 러너만 보여야 한다.
  - 결과: 시험용 숫자(드림 러너 1,280분 · 2,653판, 수호대 90분 · 60판, 나머지 13분 이하)로 열어 두 카드에만 배지가 붙는 것 확인.
